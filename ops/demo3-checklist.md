# จุดสาธิต 3 — ตรวจและให้รางวัลได้ (จบระยะ 5)

ครูลองเองบน **`https://phase-7.kemi-classroom.pages.dev`** (ลิงก์ preview ต่อ kemi-dev — มีแถบ “ระบบทดสอบ · ใช้ข้อมูลสมมติเท่านั้น” ด้านบน) — **ไม่ใช่ `https://kemi-classroom.pages.dev`** ซึ่งเป็นระบบจริง (kemi-prod) ตั้งแต่ 25 ต.ค. 2026 · ตามแผนเปิดใช้เร็วรวมกับจุดสาธิต 4 (go/no-go) — ท้ายรอบทวนรายการ “พร้อมนำร่อง” DEVELOPMENT_PLAN ส่วน 5 ร่วมกัน ด้วย **บัญชี Google ของครูเอง** ส่วนผู้พัฒนาถือ **บัญชีนักเรียนทดสอบ** (อนุชา) บนอีกเครื่อง

- ใช้ห้อง `เคมี 5/4 (ทดสอบ 2)` (รหัส `AREE9V`) ในภาคเรียน “ภาคเรียนทดสอบ 2 (สมมติ)” — รายชื่อในห้องเป็นชื่อสมมติทั้งหมด
- **ห้ามใช้ข้อมูลหรือรูปงานของนักเรียนจริง** — รูปที่ส่งเป็นกระดาษที่เขียนเอง สิ่งของ หรือกระดาน ห้ามมีหน้า ชื่อ หรือผลงานของนักเรียน
- **ห้ามกด “เริ่มภาคเรียนใหม่” หรือ “จบภาคเรียน”** ในหน้าภาคเรียนและข้อมูลเก่า (T07) ระหว่างสาธิต — ดูหน้าได้ แต่ไม่กดปุ่มทั้งสอง
- ไม่ต้องนำเข้ารายชื่อ เอานักเรียนออก หรือแก้การผูกบัญชี (ไม่อยู่ในรอบนี้)

> **งบ B2 รายวันใช้ร่วมทั้งบัญชี** (ดาวน์โหลด 1 GB · Class B 2,500 · Class C 2,500 ต่อวัน รีเซ็ต 07:00 น.) — ส่งงานครั้งละ 1–2 รูปเล็ก ๆ (รูปจากกล้องปกติ ระบบย่อให้เอง) เปิดดูรูปเท่าที่ต้องตรวจ อย่าวนเปิด/ดาวน์โหลดไฟล์ซ้ำ ๆ และไม่ต้องส่งออก ZIP · ถ้าเห็นข้อความ “วันนี้เปิดไฟล์ครบโควตาของระบบแล้ว…” ให้หยุดส่วนที่ใช้ไฟล์ แล้วจดเวลาไว้

## เตรียมก่อนวันสาธิต (ผู้พัฒนาทำ)

1. Google Cloud Console → โปรเจกต์ของ OAuth client `kemi-dev` → **Google Auth Platform → Audience → Test users** → ดูว่ามีอีเมลครูแล้ว ถ้ายังไม่มีให้ **Add users** (แอปยังเป็น Testing)
2. ล็อกอินบัญชีผู้ดูแล → `/admin` → **บัญชีครู** → อีเมลครูต้องอยู่ในรายการที่ใช้งานอยู่ และผูกกับครูคนเดิม `ครูเคมี (dev)` (ถ้าไม่มีให้ **เพิ่มบัญชีครู** แล้วเลือก `ครูเคมี (dev)` ไม่เลือก “ครูคนใหม่”) — ไม่ต้องบอก Claude ว่าอีเมลอะไร
3. บัญชีนักเรียนทดสอบ (อนุชา) ล็อกอินไว้ในเครื่องของผู้พัฒนา และอยู่ในห้อง `เคมี 5/4 (ทดสอบ 2)` แล้ว
4. เตรียมรูปในเครื่องนักเรียน 2–3 รูป (กระดาษที่เขียนสูตรเคมีเอง)

## จดกลับมาให้ Claude

- ข้อ 1–20 ผ่าน/ไม่ผ่าน (ถ้าไม่ผ่านถ่ายหน้าจอข้อความที่ขึ้น) และช่อง “อยากเปลี่ยน?” ทุกข้อที่มี
- ตารางค่าเริ่มต้นข้างบน
- เครื่องที่ครูใช้ (รุ่น + เบราว์เซอร์) และเครื่องนักเรียน
- เห็นข้อความโควตา B2 หรือไม่ (เวลา)
- งานสาธิตเก็บไว้ได้ หรือบอก Claude ถ้าอยากล้าง

ข้อที่ครูอยากเปลี่ยน Claude จะไม่แก้โค้ดทันที: กติกาใหม่ต้องลง `SYSTEM_SPEC.md` / `UX_DESIGN.md` ใน Claude app ก่อน แล้วจึงเพิ่มเป็นงานย่อยใน `PROGRESS.md`
